# КАРО — лендинги заявок и админка

Вариант **«Роскошный максимум»**: два продукта, несколько посадочных, заявки в свою административную панель и письмо менеджеру.

## Что внутри

| URL | Содержание |
| --- | --- |
| `/` | Сводная страница: выбор услуги и динамическая форма |
| `/keys` | Ключи от зала |
| `/event` | Мероприятие в КАРО |
| `/feedback` | Обратная связь: контакты и форма |
| `/admin` | Канбан заявок |
| `/admin/catalogs` | Справочники: списки записей и отдельные страницы редактирования |
| `/admin/banner` | Баннер между героем и услугами на главной |
| `/admin/feedback` | Входящие обращения со страницы обратной связи |
| `/admin/users` | Пользователи админки (только администратор) |

Стек: Next.js 16, PostgreSQL, Prisma, JWT-сессии, Nodemailer. Расписание и репертуар — `https://api.karofilm.ru`.

Нужны **Node.js 22+**, **Docker Desktop** и свободный порт **5432**.

Prisma читает `DATABASE_URL` из `.env`, Next.js — из `.env.local`. Копируйте пример в **оба** файла.

## Первый запуск (после клонирования)

В корне проекта:

```bash
npm install
cp .env.example .env
cp .env.example .env.local
```

В обоих env-файлах замените `AUTH_SECRET` на длинную случайную строку. Пароли админки можно оставить как в примере для локальной работы.

Поднимите базу, примените миграции из репозитория и заполните справочники:

```bash
docker compose up -d
npx prisma migrate deploy
npx prisma db seed
npm run dev
```

Сайт: [http://localhost:3000](http://localhost:3000)  
Админка: [http://localhost:3000/admin](http://localhost:3000/admin)

Вход по умолчанию:

- администратор: `admin@karofilm.ru` / `changeme`
- оператор: `operator@karofilm.ru` / `changeme`

Письма менеджеру уходят только если заполнены `SMTP_*` и `NOTIFY_EMAILS`. Без SMTP заявки всё равно сохраняются.

## Повторный запуск

Если проект уже ставили и база на месте:

```bash
docker compose up -d
npm run dev
```

Миграции повторно применять не нужно, пока не подтянули новые из git. После `git pull`, если появились файлы в `prisma/migrations/`:

```bash
npx prisma migrate deploy
npx prisma db seed
```

`db seed` безопасен для повторного запуска: пользователи и справочники обновляются, а не дублируются.

## Остановка и перезапуск

Остановить только сайт (терминал с `npm run dev`): `Ctrl+C`.

Остановить PostgreSQL, но сохранить данные:

```bash
docker compose stop
```

Полностью выключить контейнер базы:

```bash
docker compose down
```

Данные Postgres живут в docker-томе `luxe_pg` и не пропадут после `down`. Чтобы стереть базу и начать заново:

```bash
docker compose down -v
docker compose up -d
npx prisma migrate deploy
npx prisma db seed
```

Перезапустить сайт:

```bash
# Ctrl+C в терминале dev-сервера, затем:
npm run dev
```

Перезапустить базу:

```bash
docker compose restart
```

Порт 3000 занят — остановите старый `next dev` или откройте другой: `npm run dev -- -p 3001`.

## Справочники аренды

«Ключи от зала» и «Мероприятие» берут кинотеатры и залы **не из всей сети КАРО**, а из каталога в `/admin/catalogs`. У зала две стоимости аренды: **пн–пт** и **сб–вс**. После первого `seed` там уже есть заглушки (Москва: Атриум, Октябрь, Авиапарк). Форматы и тексты преимуществ можно править в админке — финальный копирайт заказчик может заменить позже.

Обращения со страницы `/feedback` попадают в `/admin/feedback`, отдельно от заявок на услуги.

Горизонтальные **перетяжки** и **карусель** на главной настраиваются в `/admin/banner`. Перетяжки — JPG/PNG до 8 МБ. Карусель — до 5 постов (картинка 1200×900, 4:3, плюс текст и раскладка), интервал перелистывания задаётся там же.

## Тема «Осень в КАРО»

Публичные страницы оформлены в сезонной кампании: тёмный графит с винно-коричневыми градиентами и плёночным зерном, бежевые «бумажные» элементы, акцидентный заголовочный шрифт и коллажные детали. Админка остаётся нейтральной — это рабочий инструмент.

Токены лежат в `src/app/globals.css` (`.theme-autumn`), декоративные элементы — в `src/components/landing/AutumnDecor.tsx` и классах с префиксом `autumn-`. Переключение без правок кода:

```bash
NEXT_PUBLIC_SITE_THEME=classic   # прежнее оформление
NEXT_PUBLIC_SITE_THEME=autumn    # сезонная тема (по умолчанию)
```

После смены переменной нужен перезапуск `npm run dev` или пересборка.

### Фотографии кампании

Съёмка кампании лежит в `public/autumn`:

- `hero-banner.png` — широкий баннер героя (2:1), во всю ширину блока «Тёплый сезон — в тёмном зале»;
- `ticket.jpg` — запасной кадр кампании (вертикальный).

PNG для баннера нормален: `next/image` сам отдаст WebP. Чтобы обновить визуал, замените файл с тем же именем.
